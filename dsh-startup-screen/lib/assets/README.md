// 把你的音频文件放到这里，文件名与 lib/splash.js 里的音频槽位对应：
//
//   line-1.mp3   第 1 步台词（需要访问许可）
//   line-2.mp3   第 2 步台词（身份资料确认）
//   line-3.mp3   第 3 步台词（接收访问需求）
//   line-4.mp3   第 4 步台词（开始读取权限）
//   line-5.mp3   第 5 步台词（读取完毕 · 核验通过）
//   line-6.mp3   终幕欢迎语
//   sfx-tick.mp3       单声「哒」
//   sfx-ticks-run.mp3  整串「哒」
//
// 素材缺失时，splash.js 会自动回落到系统 TTS（语音）或合成音（音效），
